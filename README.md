# Michael Ibea — Data Engineering Portfolio

A responsive, recruiter-friendly, multi-page portfolio built with plain HTML and CSS. All assets are local, so the site works by opening `index.html` directly.

## Pages

- `index.html` — profile, role positioning, impact metrics, and quick links
- `experience.html` — complete experience and education
- `projects.html` — five selected data engineering initiatives
- `skills.html` — categorized technical and collaboration skills
- `contact.html` — verified contact details and availability

## Local use

Extract the ZIP and double-click `index.html`. No build step or web server is required.

## GitHub Pages

Create a repository, upload the contents of `portfolio-folder` to the repository root, then open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
